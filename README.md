# 浙大 MBA 论文指导 Skill

由哆啦A胡整理，面向浙大MBA同学的论文研究与写作辅助。**非浙江大学官方项目**。

## 下载与解压

下载本仓库中的 **`mba-thesis-coach-protected.zip`**，使用支持AES加密ZIP的解压工具（如新版7-Zip或WinRAR）打开，输入维护者提供的分享密码。

密码不在公开仓库中，请向分享者索取。GitHub没有网盘式下载提取码，本项目通过压缩包加密保护内容。

仓库只公开本说明、校验值和加密包，不公开skill源文件。原课件、完整录音转写、学校Word原模板及个人材料不包含在分享包中。

## 包内内容

- 约1.26万字的课程详细学习总结，整合8份课程及模板材料。
- `zju-mba-thesis-coach`技能入口及8份专题参考。
- 七部分开题报告、三级提纲、调研与证据台账、问题原因措施对应表、实施评价、评审回应及答辩模板。
- 来源说明、版本冲突和AI纪要纠错、使用示例、验证记录。
- 原创内容的MIT许可说明；不涉及第三方原件再分发。

## Codex安装

解压后，把下面的整个文件夹：

```text
mba-thesis-coach/skills/zju-mba-thesis-coach
```

复制到：

```text
~/.codex/skills/zju-mba-thesis-coach
```

Windows默认位置：

```text
%USERPROFILE%\.codex\skills\zju-mba-thesis-coach
```

保留文件夹内的 `SKILL.md`、`references/` 和 `agents/`。使用自定义 `CODEX_HOME` 时，以该目录下的 `skills/` 为准。

在下一轮对话或重新打开会话后调用：

```text
使用 $zju-mba-thesis-coach，根据我的企业背景和资料，
判断论文类型，给出资料缺口和七部分开题报告方案。
```

其他支持Skill的Agent可按其目录规范复制同一技能文件夹；不支持Skill时可让AI阅读入口及相关参考。

## 使用边界

学院现行正式规范及当批次通知优先。材料含历史版本和转写疑点，技能已单独标注；不能替代导师指导、真实调研和文献核验，不保证论文通过。

不编造问卷、访谈、数据、实施成效和参考文献。尚未实施的方案只写预期效果和验证计划。

## 文件校验

`SHA256SUMS.txt`记录加密ZIP的SHA-256值，用于核对下载文件完整性。不要把密码或自己的论文数据提交到本仓库的公开Issues。
